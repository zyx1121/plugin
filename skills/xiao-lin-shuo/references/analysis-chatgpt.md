## CONFIRMS — 既有 pattern 再現

- **反預期開場 + open loop**:開場即 demo + 名場面轟炸「又是拿美國的醫學牌照又是參加司法考試又能寫小說編代碼」(00:37),問題鏈 roadmap「他又有什麼問題呢?巨頭們又如何應對?他到底會讓誰失業呢?」(00:37–00:56)全片依序回收;自嘲式示弱「我要是按他這個講,估計沒兩期我這粉就該掉光了」(00:20)。
- **問題鏈遞迴(原樣遷移到技術演化史)**:pattern matching「單憑這種模式匹配是不可能實現的」(03:20)→ 機器學習 → 神經網絡「學到後面的時候前面都忘了」(06:29,RNN 缺陷)→ Transformer → GPT-3「再怎麼加大參數量,提升都非常有限」(11:25)→ RLHF → ChatGPT。
- **自創框架 + 術語押後**:自創「套路性工作」框架(25:43–26:03);RLHF 先機制後命名「專業術語就叫人工反饋的強化學習」(11:42)。
- **數字錨參照系**:「一代 1.2億 → GPT-2 15億 → GPT-3 直接上升了100倍,1750億」(10:30–11:23);「谷歌搜索份額 93%…Bing 只有 3%,搜索廣告佔谷歌總收入60%」(20:28);「每個問題消耗的能源大概是谷歌搜索的10到100倍」(21:54)。
- **衝突先行的連續劇**:AI 戰爭掛在微軟 2/7 vs 谷歌 2/8 發布會對決(22:37),「谷歌把自己的腰給扭掉了」(22:19);配音:谷歌 Code Red「這是我們生死存亡的關鍵時刻了」(22:19)。
- **代價緊跟成功**:月活破億(14:07)立刻翻「經常犯我們看著非常弱智的錯誤」「大量編造答案…在那給你硬扯」(15:49–16:40);收益封頂制剛立完就拆漏洞(10:18);微軟注資雙贏後緊接「你說微軟能投的是情懷嗎?」(10:30)。
- **口頭禪(子集)**:「好傢伙」(00:37, 18:06);自問自答「那為什麼火呢?」(04:06);第二人稱推演(20:08);擬聲「誇誇一頓學」(08:24)「啪就先砸進去了100個億」(25:17)。

## CONTRADICTS

- **「這是什麼概念呢?」全片未出現**(「好問題喲」「NO NO NO」「咱就是這麼嚴謹」也缺席)。參照系機制照樣成立,改用倍數/對照組直陳。→ 口頭禪表=工具箱,非每片必配。
- **Running gag 為零**——幽默全是一次性梗;全片回收的錨是嚴肅的「圖靈測試」而非笑點。→ 放寬為「全片回收錨(gag 或嚴肅判準皆可)」。
- **收尾第四型**:開放式雙面意象「能見證AI這麼神奇的發展還是個挺激動的事,潘多拉的魔盒也在一點一點被我們打開了」(28:38)——題材未完結時,用雙面意象留懸收尾。
- **人物暱稱化未現**:圖靈、馬斯克全用本名;人格化改由「擬人化公司」承擔。

## NEW

- **Demo 三用:hook / sandbox / 論證**。開場實測「咱就直接問問ChatGPT能不能幫我寫一個視頻大綱,你看1234567就列出來了」(00:00)當 hook;童話 demo「我告訴他不對小林是個女的,你重編…打敗了邪惡的女巫成了英雄」(26:03–32)論證「套路性工作」;拿自己當測資「我要是問ChatGPT你知道小林說嗎?他就只能說他不知道。那我要是問Bing呢?…說的我都有點不好意思了」(19:31–46)。虛構 sandbox 被「產品本身」取代。【產品可實測題材通用;財經題材做不到】
- **深度預算法則:深度由問題鏈承重決定,不由技術重要性決定**。RNN 缺陷一句講完(只負責引出 Transformer);Transformer 零機制展開,只給比喻黑箱「就像打通了任督二脈」+命名彩蛋「BERT 裡頭的T,ChatGPT 裡頭的T,都是指這個Transformer」(07:01);反而 next-token 機率用「我很開心/我很健康/我很著急/我很餓」講透(14:56–15:23),因為它承重「為什麼會胡說八道」(15:49)的全部解釋。attention、loss 一概不碰。【通用,直接入 Engine 2】
- **擬人化公司當劇中角色**:谷歌「能不慌嗎」(20:08)、「露怯」(23:52),微軟「立刻衝了過來」(10:19)、「很陰險」(19:46)——情緒動詞+動機推演把公司演成人。【通用,機構主角題材】
- **借用歷史判準當全片縱軸**:圖靈測試開頭立起(01:12),當每代機器人的量尺(03:20、04:49),半世紀後宣告通過(12:20),再引圖靈本人反問升一層「與其問機器能像人類一樣思考嗎,倒不如問機器能做人類做的事嗎?有點深度了」(16:43–17:13)。題材自帶經典判準時,借用它而非硬造框架。【通用於科學/技術史題材】
- **偷懶宣言反向 hook**:「我就圖省事啊,咱就直接問問ChatGPT」(00:00)——工作量證明的反轉,示弱+偷懶自然帶出 demo。【產品能替講者工作時成立】
